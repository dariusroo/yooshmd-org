Drop `.txt` chat transcripts in this folder to have them show up at `/chats`.

**Format:** paste in the raw text you get from selecting and copying a
chatgpt.com conversation — turns are separated by lines that read exactly
`You said:` and `ChatGPT said:`.

**Filename → title & order:** the filename becomes the slug and the sidebar
title (dashes/underscores become spaces, each word capitalized). Prefix
filenames with numbers to control sort order, e.g.:

```
01-intro-to-glp1s.txt   -> "Intro To Glp1s"
02-side-effects-qa.txt  -> "Side Effects Qa"
```

This README is ignored since it isn't a `.txt` file.
